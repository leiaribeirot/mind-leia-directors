## Escopo e limites

Este é um pacote dos três componentes, não um backup integral do acervo pessoal. Conversas privadas brutas, entrevistas, avaliações pessoais e materiais com terceiros permanecem na origem local; a lente ainda menciona parte desse acervo histórico. Ausência desses arquivos no pacote não autoriza inventar seu conteúdo.

O Director Arcadia depende de outros módulos, registro de ateliers, scripts e infraestrutura do projeto Arcadia. A cópia não foi validada como aplicação independente. Seus comandos originais podem exigir execução dentro do Arcadia completo. Presença de arquivos não prova ativação de agentes nem funcionamento de serviços.

Transcrições automáticas podem conter erros; confira áudio e código antes de implementar regras. As instruções e fontes continuam privadas; este repositório não concede autorização de publicação ou redistribuição. Autoria original dos componentes e referências é preservada.
